# 更新说明：0.23.22 相较上一公开版

上一公开版：`0.20.0`  
本版：`0.23.22`  
跨度：0.21 → 0.22 → 0.23 共 69 个可追溯的版本条目（`CHANGELOG.md` 里逐条可查）

这份文档只讲**用户能感觉到的东西**，不讲内部重构。每条都指得到代码或工具。

---

## 一、记忆从"记下来"变成"能查、能看、能解释"

### 1. 记忆三件套（0.23.0）

上一版只能 `recall` 一把梭，问"你记得什么"拿不到全貌。本版拆成三个工具：

```text
cognition_mem_timeline     按时间看这段关系里发生过什么
cognition_mem_observation  看她现在对某个人/某段关系是什么认识
cognition_mem_raw          看原始条目和证据 id（排查"她为什么这么说"）
```

为什么要三个：时间线回答"发生过什么"，观察回答"她现在怎么想"，原始条目回答"凭什么"。
一个工具同时干这三件事，模型只会挑最省事的那种用。

### 2. 关系与约定成为一等公民（0.23.15–0.23.18）

```text
kind=relationship   她与主人是什么关系（角色、场景、证据数）
kind=agreement      称呼、格式、期限类约定；支持 expiresAt 到期、撤销、场景排序
```

上一版这些散落在 fact/preference 里，抽出来也是乱的。现在：

```text
「以后叫我主人」     → 约定，role 字段，可撤销
「到年底前都这样」   → 约定，带 expiresAt，过期自动退场
「你是我的赛博伴侣」 → 关系，进面板「关系与约定」区块
```

修掉的坑：0.23.18 前，两条格式类约定会互相覆盖——后一条把前一条顶掉，
等于"约定只有最后一条生效"。现在按场景分开存。

### 3. 抽取精度：先修假阳性，再补条真召回（0.23.13）

上一版把「我不喜欢这样」也抽成偏好，把反问句抽成事实。本版按主人定的 A+B 范围收窄，
假阳性明显下降；代价是召回变窄——**知道这个代价，比不知道强**。

### 4. 重复事件治理（0.23.7–0.23.12）

根因是宿主**每 56 秒重载一次插件**（中位数），模块内存里的状态每次归零。
上一版靠内存去重，重载后立刻重复写入。本版：

```text
去重状态落盘（inject-state.json）
重叠判定 + 落盘（同一条消息只记一条）
历史重复事件迁移（用户批准后执行）
```

实测重复率从 20% 降到个位数，注入不再连轮重复塞同一条记忆。

## 二、检索：能说"没有"了

### 5. 检索基线先量出来（0.23.x）

```text
专有名词查询 hit@1     ~80%
同义改写 hit@1         0%（词表外）
日常负例被硬塞         15/15
```

上一版没有任何公开基线——"记得准不准"全靠感觉。现在每个数字都能用
`scripts/eval-retrieval.mjs` 复现。

### 6. 同义词表（0.23.20）

51 组 / 154 词，查询侧扩展，同义词命中的频次和覆盖率打六折（防止「打车」命中「攻击」）。

```text
同义词覆盖查询 hit@1   0% → 23%
同上 hit@8             0% → 53%
专有名词查询           不变
负例拒识               不变
```

歧义单字（打/搞/弄）一律不入表，有测试盯着。

### 7. 拒识阈值：先有标注，再定数（0.23.22）

上一版只有"零命中才拒"，等于没有拒识——**10 条日常负例里 15/15 被硬塞结果**。
本版建了 22 条标注集，在同一份数据上比了 7 类判定规则，采用：

```text
覆盖率 < 0.25 且 命中词最高 idf < 5  → 拒识
```

```text
误拒（该召却拒）  0/7   ← 一条该召的都没伤
误纳（该拒却召）  6/15  ← 从 15 条降到 6 条
```

为什么不是"覆盖率多少以下一律拒"：长查询「鱼，你晚上会休息吗？」覆盖率只有 0.11，
但它确实命中一条相关往返（maxIdf 5.71）。只看覆盖率会把它误拒。maxIdf 是"有没有命中要害"的兜底。

**诚实说**：剩下 9 条误纳是"稀有词巧合"，词法统计分不开稀有的无关二元组和真正相关的专有名词。
再往下调阈值只会开始误拒正常追问。要突破得靠语义判定，不是调参数。

### 8. 自己那句话不再挤掉真记忆（0.23.22）

检索前剔除"本轮这句话自己"——它已入库时文本完全相同、必然 100% 命中，
会把真正该回忆的内容挤到第二名。这是真 bug，不是优化。

## 三、面板：从"看个状态"到"能对账"

### 9. 面板快照写盘 + 真实数据（0.22.21–0.22.24）

上一版面板读不到插件运行时状态，只能显示示例。本版：

```text
插件运行中写 live-snapshot.json
面板读快照，带兜底与更新时间
没有数据就不渲染那个区块（空着比显示 0 更诚实）
```

### 10. 记忆健康区块

```text
最近注入了什么、注入次数、重复命中（repeatHits）、旧触发未命中（oldTriggerMisses）
```

回声指标是代理指标，不是"模型真的用上了"的证明——面板上也没这么写。

### 11. 布局审计（0.23.14）

900 / 1280 / 1600 三档宽度实测：无横向溢出、无裁剪、最小字号 11px。
预览图 `panel/overview-preview.png`（QQ 号在字符串字面量里做过遮罩）。

## 四、这一版没做的事

```text
向量召回      能力写完了，实测会拖垮拒识，不接入（数据在 检索设计.md 第八节）
跨会话记忆    scope 严格隔离，刻意不做
模型抽取      纯规则抽取，漏召是已知代价
注入路径同义词  注入走字符重合判定，与 recall 是两套逻辑，本版不动
```

"没做"在这里不是谦虚，是边界。看到没做的能力，就知道别指望它。

## 五、结论：这版比上版好在哪

一句话：**上一版会记，这一版能对账。**

具体三件事：

1. **可解释**。上一版她说"我记得你说过…"，你没法验证。现在 `cognition_mem_raw` 给原始条目和证据 id，
   `cognition_mem_observation` 给当前认识，时间线给上下文。记得对不对，能查。

2. **会说"没有"**。上一版任何问题都能硬塞几条相关记忆回来，看起来博学，实际是把无关内容当证据。
   本版拒识从 0/15 到 6/15，且**一条该召的都没误伤**。宁可说"没有可靠的相关记忆"，也不硬塞。

3. **重复和噪声降下来了**。宿主 56 秒重载导致的重复写入、连轮重复注入、格式约定互相覆盖、
   自检索挤占——这几个都是上一版真实存在的 bug，本版逐个修掉并留了测试。

**没变好的地方也要说**：抽取仍是纯规则，句式一变就漏；同义改写只覆盖表内 154 个词；
注入路径的相关性判定仍是字符重合，比 `cognition_recall` 粗一档。这些是下一个版本的工作，不是这版的优点。
