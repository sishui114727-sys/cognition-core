# cognition-core 数据收集协议

版本：`public-data-v1`  
生效日期：2026-10-27  
维护者：`似水未来`  
联系邮箱：`2736629638@qq.com`  
适用项目：`cognition-core`  
协议性质：**自愿、明示同意、只收集匿名聚合指标**

> 本文是项目的数据处理说明，不构成法律意见。公开上传前，维护者应根据所在司法辖区咨询专业人士，并补齐主体信息与隐私政策。

---

## 1. 是否默认收集

**否。**

`cognition-core` 默认：

```text
不联网上传
不发送遥测
不包含第三方统计 SDK
```

只有用户主动运行导出脚本，并把生成的 JSON 手动交给维护者，才发生数据提供。

---

## 2. 收集目的

仅用于：

```text
评估记忆/身份/权限架构是否可用
统计事件规模、来源分布、动作成功率
发现版本兼容性和性能问题
改进公开版本
```

不用于：

```text
广告
出售数据
对个人画像
信用评估
训练可识别个人的模型
```

---

## 3. 收集什么

脚本：

```text
scripts/public-data-export.mjs
```

默认只输出：

```text
schemaVersion
consentVersion
generatedAt（只到日期）
appVersion
kThreshold
事件总数
认知总数
人物总数
关系总数
SelfModel 版本数
活跃天数（粗粒度）
按 source.type 的事件数
按 scope.kind 的事件数
按 privacy 的事件数
按 cognition.status 的数
按 action/feature/allowed 的动作数
被抑制的小样本单元数
```

**所有分布单元少于 k=5 的会被抑制，不输出。**

---

## 4. 明确不收集

```text
聊天正文
群名 / 群号
QQ 号 / 昵称 / 备注
联系人关系
SelfModel 的价值 / 承诺 / 边界 / 自我叙事
人物印象原文
事件 text
事件 source.ref
图片 / 视频 / 表情 URL
Cookie / SESSDATA / token
IP / 主机名 / 用户名
绝对文件路径
精确到秒的时间戳
API key
支付信息
```

导出脚本不会读取表情库、音乐库、聊天存档、QQ 配置或浏览器 Cookie。

---

## 5. 数据最小化

公开数据默认只保留：

```text
计数
枚举分类
版本号
日期
```

不保留自由文本。  
不保留可回溯到具体会话或个人的键。

---

## 6. 同意方式

用户必须显式运行：

```text
--consent public-data-v1
```

没有这个参数，脚本拒绝运行。

同意文本见：

```text
docs/CONSENT.zh-CN.md
```

---

## 7. 保存期限

维护者收到聚合文件后：

```text
最长保存 90 天
用于本次版本评估
到期删除
```

如果用于公开统计页面，只保留汇总结果，不保留单份原始导出。

---

## 8. 共享

不会出售。  
不会公开单份可回溯数据。  
可能公开：

```text
总体计数
版本分布
聚合后的成功率
```

公开前再次检查小样本抑制。

---

## 9. 撤回

用户可以：

```text
不运行导出
删除本地导出文件
联系维护者删除已提交文件
```

因为导出文件不含标识符，维护者无法从聚合数据反查是谁提交的；  
如果需要删除，请保留提交时的文件名或提交时间，便于定位。

---

## 10. 安全

建议：

```text
导出后先打开 JSON 检查
不要附带 events.jsonl / persons.jsonl / 聊天截图
不要附带日志
不要附带备份
使用加密渠道提交
```

---

## 11. 未成年人

本项目不面向未成年人收集数据。  
如果使用者是未成年人，应由监护人决定是否提交。

---

## 12. 第三方平台

B站、小黑盒、QQ空间等 Adapter 只读取/发送用户自己有权使用的内容。  
平台条款、账号风险、内容合规由使用者自行承担。  
数据收集协议不授权绕过任何平台限制。
