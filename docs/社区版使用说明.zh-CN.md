# cognition-core 社区版使用说明

版本：`0.23.22`  
宿主：QQ Agent（QQA）0.4.7 及以上，Electron 运行时  
定位：本地优先的**认知与身份核心**，不是人设卡，不是云记忆服务

---

## 0. 三分钟上手

```text
1. 解压发布包
2. 把 plugin/ 整个目录放进：<QQA 安装目录>/resources/app/plugins/cognition-core
3. 重启 QQ Agent（一定要完全退出，不是关窗口）
4. 打开设置 → 插件 → 认知核心 → 填「主人 QQ 号」
5. 在设置里打开「启用认知核心」，保存
6. 私聊里说一句话，比如「我喜欢吃甜的」
7. 打开权限面板确认它记下了
```

面板入口：设置里 cognition-core 的「打开权限面板」，或直接打开

```text
<QQA 安装目录>/resources/app/plugins/cognition-core/panel/overview.html
```

面板是**只读**的：它显示当前状态，不负责改设置。改设置请回设置表单。

## 1. 它到底在做什么

一句话：**把"她是谁、她知道什么、她能做什么"拆成可审计的数据，而不是塞进一张人设卡。**

```text
身份      → Identity Anchor / Person / Relationship
经历      → Event（append-only，一条消息一条）
阶段      → Episode（一段时间的经历归纳）
长期认识  → Cognition（事实 / 偏好 / 边界 / 约定 / 关系）
自我描述  → SelfModel（版本化，可回退）
行动      → ActionBus + Gateway（权限等级、时间窗、限额、冷却、审计）
表达      → 运行时生成，不读取固定人设卡
```

四个关键设计：

```text
1. 不默认注入人设卡     每轮注入的是"本轮话题相关的少量记忆"，不是一段固定性格总纲
2. 所有写入 append-only  认知变更保留 revision / 变更原因 / 被谁取代，可追溯
3. 动作先过闸门          owner-only + 权限等级 + 时间窗 + 日/周上限 + 冷却 + 确认
4. 数据留在本地          默认不联网、不遥测；导出聚合数据必须你手动运行脚本
```

## 2. 设置项说明

| 设置 | 作用 | 建议 |
|---|---|---|
| 主人 QQ 号 | owner-only 判定。留空 = 未绑定主人，所有本地/行动能力默认拒绝 | 必填 |
| 启用认知核心 | 总开关。关闭后不读不写不执行 | — |
| 最高权限等级 | L0 只读 / L1 低风险 / L2 社交 / L3 公共表达 / L4 高影响 | 从 L2 开始 |
| 时区 | 时间窗、日/周上限、日期解析都按它算 | 按你所在地填 |
| 私聊/群聊主动发言 | 主动私聊、群内接话；受时间窗、日/周上限、冷却限制 | 默认关闭更安全 |
| 贴纸/音乐 | 贴纸发送、音乐检索；同样受限 | 按需 |
| B站/QQ空间/小黑盒读取 | 只读抓取公开内容；会记入动作审计 | 按需 |
| B站评论 / 空间发布 | 公共表达，默认关闭，需 L3 + 确认 | 极谨慎 |

**为什么默认关公共动作**：发出去的内容删不干净，账号风险由你承担。核心只负责"按规矩发"，不保证平台一定成功。

## 3. 十七个工具

工具全部 `owner-only`：只有主人 QQ 能触发。

**记忆**

| 工具 | 作用 |
|---|---|
| `cognition_recall` | 按当前会话范围检索相关事件与认知，返回有预算的上下文包；查不到会明确说"没有找到可靠的相关记忆"，不硬塞 |
| `cognition_mem_timeline` | 按时间看这段关系里发生过什么 |
| `cognition_mem_observation` | 看它对某个人/某段关系的当前认识 |
| `cognition_mem_raw` | 看原始条目（含证据 id），排查"它为什么这么说" |
| `cognition_mem_terms` | 看记下的关系与约定（角色、场景、到期、证据数） |
| `cognition_self` | 读/写自我模型（版本化） |
| `cognition_status` | 运行状态、计数、最近动作 |
| `cognition_consolidate` | 手动触发一次整理（把事件提炼成认知） |
| `cognition_study_search` | 在学习管线的手账 / 稿件 / 札记里检索（只读）。要先在设置里打开「读取学习手账」，没装学习管线时保持无效果 |

桥打开后，`cognition_recall` 会在结果尾部附「学习管线里也有」——只给标题、日期和手账 id，正文要用时再单独取。
记忆侧判定"没有可靠内容"但手账里有明确命中时，它会如实说"记忆里没有，但手账里有"，不合并成一句模糊的话。

**行动**

| 工具 | 作用 |
|---|---|
| `cognition_private_send` | 主动私聊（受时间窗/上限/冷却） |
| `cognition_qzone_read` / `cognition_qzone_publish` | 读空间主题 / 发空间（L3 + 确认） |
| `cognition_bili_search` / `cognition_bili_video` | B站检索与视频信息 |
| `cognition_xhh_feed` | 小黑盒信息流 |
| `cognition_sticker_list` / `cognition_sticker_send` | 表情库与发送 |

## 4. 数据在哪、长什么样

```text
<QQA 安装目录>/data/plugin-data/cognition-core/core/
  events.jsonl              经历（append-only）
  episodes.jsonl            阶段归纳
  cognitions.jsonl          认知（带 revision / 变更原因 / 取代关系）
  self-model.json           自我描述
  persons.jsonl             人物
  relationships.jsonl       关系
  action-log.jsonl          动作审计
  inject-state.json         注入去重与遥测
  vectors.bin               （可选）语义向量侧车，本版未接入运行时
```

全是本地 JSONL/JSON，没有数据库，没有云端。

## 5. 面板看什么

面板四块：

```text
权限等级与状态        当前 L 几、哪些能力开着
记忆健康（注入遥测） 最近注入了什么、命中率、回声指标
关系与约定            记下的关系/约定（角色、场景、到期、证据数）
功能卡片              每个功能的开关、时间窗、限额、冷却
```

没有内容时对应区块不渲染——**空着比显示 0 更诚实**。

## 6. 它会记什么、不会记什么

会记：

```text
你在私聊/群聊里说的触发文本 + 它的回复
从这些文本里提炼的偏好、事实、边界、约定、关系
人物身份（稳定 QQ 号）与关系
它自己做过的动作（审计）
```

不会记：

```text
其他人没对你说的私聊
你的密码 / Cookie / SESSDATA / token
图片和视频本体（只留引用与说明）
你电脑上的其他文件
```

**边界提醒**：群聊里他人的发言也会进入记录，这涉及第三方隐私。公开你的 `data/` 目录前请想清楚。

## 7. 贡献聚合数据（可选，不自动）

默认**不联网、不遥测**。想帮助我们改进，可以手动导出聚合指标：

```text
node scripts/public-data-export.mjs \
  --data-dir "<QQA>/data/plugin-data/cognition-core/core" \
  --out public-data.json \
  --consent public-data-v1
```

- 没有 `--consent public-data-v1` 会拒绝运行
- 只导出计数与枚举分类，**不含任何正文、QQ 号、路径、时间戳**
- 所有分布单元少于 k=5 的会被抑制
- 导出的 JSON 可先自己打开看，确认无误再提交
- 协议全文见 `docs/数据收集协议.md`

提交方式：`2736629638@qq.com`（主题写 `cognition-core public-data`）。

## 8. 常见问题

**Q：装完之后它不认识我。**
A：认知需要时间积累。确认「主人 QQ 号」填对、权限等级 ≥ L2，然后正常聊天；整理是分批进行的，不会每句话都立刻变成认知。

**Q：面板显示的是示例数据。**
A：说明插件还没写出真实快照。启用插件并产生一次会话后重启面板即可。

**Q：它在群里乱接话。**
A：把「群内接话」关掉，或收紧时间窗与日上限。接话判定由 `context-chime` 之类的插件协同，冲突插件见炸机说明。

**Q：会不会和别人的人设卡插件打架？**
A：会。人设卡每轮注入固定性格，与"按需注入相关记忆"直接冲突。清单见 `docs/炸机说明（必看！！！！）.md`。

**Q：数据能直接搬走吗？**
A：可以，`core/` 目录整个拷走即可，都是纯文本。

**Q：怎么彻底卸载？**
A：停用插件 → 退出 QQA → 删除插件目录 → 按需删除 `data/plugin-data/cognition-core`。删数据不可恢复，先备份。

## 9. 出问题怎么报

请附上：

```text
版本号（plugin.json 里的 version）
QQA 版本
复现步骤（第几步、说了什么）
面板截图（把 QQ 号遮掉）
日志里含 cognition-core 的那几行
```

**不要**直接发送 `events.jsonl`、`cognitions.jsonl` 或聊天截图——里面有真实对话和第三方发言。需要时用第 7 节的聚合导出。
