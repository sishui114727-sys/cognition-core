# 风险说明

版本：0.19.0  
适用：公开上传、试用、二次分发

---

## 1. 隐私风险

核心会保存：

```text
群聊/私聊触发文本
她的回复
人物身份
关系边界
印象
动作审计
```

即使是本地 JSONL，也属于敏感数据。

风险：

```text
同一台电脑的其他用户可读
备份/网盘同步会复制
日志/截图/导出文件可能泄露
群聊内容包含第三方隐私
```

建议：

```text
使用独立系统账户
磁盘加密
备份加密
不要把 data/ 目录放进公开仓库
不要公开 events.jsonl / persons.jsonl / relationships.jsonl
```

---

## 2. 群聊第三方数据

群友没有同意被记录。  
核心记录的是“触发文本 + 回复”，可能包含他人发言。

公开收集数据的默认脚本只输出聚合计数，不输出正文。  
如果维护者以后想要原始对话，必须另立协议、逐人同意，不能沿用本版协议。

---

## 3. 公开发布风险

QQ 空间、评论、B站等属于公共动作。

```text
发出后可能被截图/转发/索引
删除不保证彻底
平台可能限流/封号
```

当前保护：

```text
QQ空间发布 owner-only
必须 confirmed=true
好友可见
内容过滤
L3 权限
```

但仍不能保证平台侧一定成功、一定可删除。

---

## 4. 平台条款风险

B站、小黑盒、QQ空间接口可能：

```text
变更
加验证码
限流
封禁
要求登录
禁止自动化
```

本项目的 Adapter 不保证长期可用，也不授权绕过平台限制。  
使用者自行承担账号和合规风险。

---

## 5. 动作风险

ActionBus 不是操作系统沙箱。

```text
插件仍以 QQA/Node 进程权限运行
文件系统访问没有内核级隔离
网络请求由宿主进程发出
```

当前有：

```text
owner-only
权限等级
时间窗
日/周上限
冷却
确认
审计
```

但没有：

```text
独立账户
容器
强制网络代理
文件系统白名单
```

不要把它当成安全边界。

---

## 6. 提示注入风险

聊天内容、网页、B站简介、小黑盒帖子、空间评论都可能包含指令。

模型可能被诱导：

```text
调用工具
泄露上下文
发公开内容
读取不该读的数据
```

当前缓解：

```text
工具 owner-only
公共动作确认
权限等级
内容过滤
```

但过滤不是万能的，尤其是语义绕过。

---

## 7. 模型错误风险

```text
认错人
编造记忆
错误总结
把群聊内容带进空间
把私聊内容说给群里
```

当前缓解：

```text
Person/Relationship 只按稳定 ID
认人卡片只追加 user
群聊不注入私聊印象
Qzone 隐私过滤
```

但不能保证 100%。

---

## 8. 数据导出风险

聚合导出仍可能在小样本下泄露信息。

当前：

```text
k=5 抑制
只输出计数/分类
不输出文本/ID/路径
```

但如果总用户极少，某些分布仍可能被推断。  
维护者公开统计时，应再次检查小样本。

---

## 9. 升级与兼容风险

```text
QQA 升级会覆盖顶栏补丁
插件 API 可能变化
旧 qzone/sticker 工具可能改名
设置保存后不自动重载
```

必须保留：

```text
备份
版本号
变更日志
回滚包
```

---

## 10. 数据丢失风险

append-only 降低覆盖风险，但不等于备份。

```text
磁盘损坏
误删 data/
JSONL 写坏
手动 dedupe/迁移
```

都会丢数据。  
请定期备份并验证恢复。

---

## 11. 公开上传前必须检查

```text
[ ] 不含 data/
[ ] 不含 events.jsonl
[ ] 不含 persons.jsonl
[ ] 不含 relationships.jsonl
[ ] 不含 action-log.jsonl
[ ] 不含配置里的主人 QQ
[ ] 不含 Cookie / SESSDATA / token
[ ] 不含聊天截图
[ ] 不含绝对路径
[ ] 不含 public-data.example.json（除非明确要捐）
[ ] 维护者联系信息已填写
[ ] 协议版本已更新
```
