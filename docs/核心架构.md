# cognition-core 核心说明

版本：0.21.0  
宿主：QQ Agent 0.4.7 / Electron  
定位：本地优先的认知与身份核心，不是人设卡，不是云记忆服务。

---

## 1. 它解决什么问题

旧方案把“她是谁”写在一张人设卡里，每轮注入：

```text
性格总纲 + 说话方式 + 口癖 + 生活设定 + 关系
```

结果是：

```text
system prompt 固定膨胀
人设和行为脱节
换会话就认不出同一个人
记忆按会话割裂
```

cognition-core 的方向：

```text
身份 → Identity Anchor / Person / Relationship
经历 → Event
阶段 → Episode
长期认识 → Cognition
自我描述 → SelfModel
行动 → ActionBus + Gateway
表达 → 运行时生成，不读取固定人设卡
```

## 3. 数据

### Event

append-only：

```text
data/plugin-data/cognition-core/core/events.jsonl
```

字段：

```text
id, time, scope, source, participants, text,
confidence, salience, privacy, metadata
```

来源类型：

```text
import / manual / legacy-mem-layered / legacy-cross-memory /
legacy-life-memory / legacy-impression / dialogue
```

### Person / Relationship

```text
persons.jsonl
relationships.jsonl
```

Person 只存身份：

```text
QQ 号、平台、显示名、isOwner、metadata
```

Relationship 只存关系：

```text
personId、role、trust、permissions、boundaries、metadata
```

### Cognition / SelfModel

```text
cognitions.jsonl
self-model-versions.jsonl
```

SelfModel 目前是 **v1**：

```text
values
commitments
boundaries
openQuestions
selfNarrative
change
```

### 审计

```text
action-log.jsonl
usage.jsonl
```

动作审计只存动作、风险、是否允许、结果，不存聊天正文。

## 4. 运行流程

```text
QQ 消息
  ↓
QQA before-context
  ↓ 收集当前发言者
before-llm-messages
  ↓ 认人卡片：只追加到 user
  ↓ ContextPack（默认关闭）
LLM
  ↓
工具调用
  ↓
ActionBus → Gateway → Adapter → 宿主动作
  ↓
after-response
  ↓ 记录 dialogue event（默认开启）
```

### 认人卡片

```text
person-cards.json
21 人 / 67 条印象
约 22KB
```

只读索引，不再每轮扫描 3831 条事件。

### 不自动注入 SelfModel

`cognition_self` 是显式工具：

```text
模型调用才读取
不进入 system prompt
不每轮注入
```

### 对话记录

`after-response` 默认把：

```text
触发文本 + 回复
```

写入本地 Event。

但：

```text
不会自动生成 Cognition
不会自动更新 SelfModel
```

这是当前版本的明确限制。

## 6. 权限模型

等级：

```text
L0 只读
L1 低风险
L2 社交
L3 公共表达
L4 高影响
```

每个功能有：

```text
enabled
时间窗（可选）
日/周上限（可选）
冷却（可选）
```

表情发送：

```text
stickerDailyLimit   默认 0 = 无限制
stickerWeeklyLimit  默认 0 = 无限制
stickerCooldownMin  默认 0 = 无冷却
```

这些是 **发送额度**。  
`meme-taste` 里的 `maxPerDay` / `maxPerHour` 是 **收藏额度**，不是发送额度，两者不要混用。

公共/数据外发/自毁动作：

```text
必须 confirmed=true
必须 owner
写入 action-log
```

## 9. 已知限制

1. SelfModel 不自动更新。
2. Cognition 不自动提炼。
3. 对话事件只追加，不自动摘要。
4. Qzone 帖子详情受 captcha 限制，未做。
5. 小黑盒只做信息流，不做帖子详情/搜索。
6. B站视频 view 接口可能 412，已回退搜索。
7. 设置保存后需要重载插件或重启 QQA。
8. QQA 顶栏补丁在 `resources/app/ui`，升级会被覆盖。
9. 权限开关不是操作系统沙箱；插件仍以宿主权限运行。
10. 本地数据没有静态加密，依赖磁盘安全。
