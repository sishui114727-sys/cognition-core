# 核心工艺 · cognition-core

**下载：[`cognition-core-0.23.22-community.zip`](cognition-core-0.23.22-community.zip)**（混淆版，576KB） · 版本 `0.23.22` · 
文档在 [`docs/`](docs/)，源码不公开。

---

> 给 AI 一个能对账的记忆，而不是一张写死的性格卡。

cognition-core 是 QQ Agent（QQA）的**认知与身份核心**插件：把"她是谁、她记得什么、她能做什么"拆成可审计的本地数据，而不是塞进一段固定的人设总纲。

本页是单页版发布说明，装法、功能、这一版改了什么、边界在哪，都在这一页。

---

## 一、一句话

**上一版会记，这一版能对账。**

它不靠"我记得你说过"来证明记性，而是给你证据 id、当前认识、时间线，让你随时查它记得对不对。

---

## 二、它是什么 / 不是什么

| 容易误会 | 实际情况 |
|---|---|
| 又一个长期记忆库 | 记忆只是四层之一：经历（Event）→ 阶段（Episode）→ 认知（Cognition）→ 自我描述（SelfModel） |
| 换皮人设卡 | **不注入固定人设**。每轮只注入本轮话题相关的少量记忆 |
| 云同步记忆 | 全部本地 JSONL，默认不联网、不遥测 |
| 万能工具调用器 | 有权限等级、时间窗、日/周上限、冷却、确认、审计；但它**不是操作系统沙箱** |

四个关键设计：

```text
1. 不默认注入人设卡   表达是运行时按记忆生成的
2. 所有写入 append-only   认知可改判、可取代、可退休，历史不删
3. 动作先过闸门   owner-only + 权限等级 + 时间窗 + 限额 + 冷却 + 确认 + 审计
4. 数据留在本地   导出聚合数据必须你手动运行脚本
```

## 三、装好之后会发生什么（三分钟）

```text
1. plugin/ → <QQA 安装目录>\resources\app\plugins\cognition-core
2. 完全退出 QQ Agent（不是关窗口）
3. 重启，设置 → 插件 → 认知核心：填主人 QQ、权限等级选 L2、打开「启用认知核心」
4. 私聊说一句「我喜欢吃甜的」
5. 打开权限面板，能看到这条被记录
6. 问「我喜欢吃什么」，看它能不能回忆
7. 问一个无关话题（比如「明天的机票价格」），它应该说「没有找到可靠的相关记忆」
```

第 7 步是这一版的重点：**会说"没有"，而不是硬塞**。

面板四块：权限等级与状态 / 记忆健康（注入遥测）/ 关系与约定 / 功能卡片。
没有数据就不渲染对应区块——空着比显示 0 更诚实。

## 四、十六个工具

**记忆（8）**

```text
cognition_recall          按当前会话检索相关记忆，返回有预算的上下文包
cognition_mem_timeline    这段时间发生过什么
cognition_mem_observation 它现在对某人/某段关系是什么认识
cognition_mem_raw         原始条目 + 证据 id（查"为什么这么说"）
cognition_mem_terms       记下的关系与约定（角色、场景、到期、证据数）
cognition_self            读/写自我模型（版本化）
cognition_status          运行状态、计数、最近动作
cognition_consolidate     手动触发一次整理
```

**行动（8）**

```text
cognition_private_send    主动私聊（受时间窗/上限/冷却）
cognition_qzone_read      读空间主题
cognition_qzone_publish   发空间（L3 + 确认）
cognition_bili_search     B站检索
cognition_bili_video      B站视频信息
cognition_xhh_feed        小黑盒信息流
cognition_sticker_list    表情库
cognition_sticker_send    发表情
```

全部 `owner-only`：只有主人 QQ 能触发。

## 五、相较上一公开版（0.20.0），多了什么

上一公开版 `0.20.0` → 本版 `0.23.22`，中间 69 个可追溯版本条目。用户能感觉到的变化：

| 能力 | 上一版 | 这一版 |
|---|---|---|
| 回忆 | 只有一把梭的 `recall` | 三件套：时间线 / 当前认识 / 原始证据，结论和原话能一路对上 |
| 关系与约定 | 混在 fact/preference 里 | 独立类型，带角色、场景、到期、撤销；面板可看 |
| 抽取 | 假阳性多（"我不喜欢这样"也记成偏好） | 收窄范围，先修假阳性；代价是召回变窄 |
| 重复记录 | 宿主每 56 秒重载一次 → 内存去重失效 → 重复写入 | 去重状态落盘 + 重叠判定，重复率降到个位数 |
| 检索 | 没有任何公开基线 | hit@1/hit@3/hit@8、拒识率都能用脚本复现 |
| 同义改写 | 完全召回不到 | 51 组 / 154 词，同义词覆盖查询 hit@1 0%→23%、hit@8 0%→53% |
| 说"没有" | 零命中才拒，等于没有拒识（15/15 负例被硬塞） | 覆盖率 0.25 + maxIdf 兜底：误拒 0/7、误纳 6/15 |
| 自检索挤占 | 本轮这句话自己排第一，把真记忆挤掉 | 检索前剔除自己，这是真 bug 修复 |
| 面板 | 只能显示示例数据 | 运行时写快照，显示真实数据；没有就不渲染 |
| 格式约定 | 两条约定互相覆盖，后者顶掉前者 | 按场景分开存，可撤销、可到期 |

## 六、结论：这版比上版好在哪

**一句话：上一版会记，这一版能对账。**

1. **可解释**。上一版她说"我记得你说过…"，你没法验证。现在 `cognition_mem_raw` 给证据 id，`cognition_mem_observation` 给当前认识，时间线给上下文——记得对不对，能查。

2. **会说"没有"**。上一版任何问题都能硬塞几条相关记忆回来，看起来博学，实际是把无关内容当证据。本版负例误纳从 15/15 降到 6/15，且**一条该召的都没误伤**。

3. **噪声降下来了**。重复写入、连轮重复注入、格式约定互覆盖、自检索挤占——四个都是上一版真实存在的 bug，逐个修掉并留了测试（200 条）。

**没变好的地方也说清楚**：抽取仍是纯规则，句式一变就漏；同义改写只覆盖表内 154 个词；注入路径的相关性判定仍是字符重合，比 `cognition_recall` 粗一档；语义向量能力写完了但**没接**——实测会拖垮拒识。

## 七、安装

```text
1. 解压发布包，把 plugin/ 整个目录复制到：
   <QQ Agent 安装目录>\resources\app\plugins\cognition-core
   （plugin.json 必须直接在这一层，不要多套一层目录）

2. 完全退出 QQ Agent，确认任务管理器里没有 QQ Agent.exe
3. 启动 QQ Agent
4. 设置 → 插件 → 认知核心：
   主人 QQ 号（必填）/ 启用认知核心 / 最高权限等级（建议先 L2）/ 时区
5. 保存后重启一次
```

确认加载成功：

```text
日志里出现：✅ 加载成功：认知核心（cognition-core v0.23.22，api v1）
工具列表 16 个，active = true
```

装之前**必须先看清冲突清单**：`docs/炸机说明（必看！！！！）.md`。人设卡类、旧记忆类插件会和它打架，清不干净会出现双写、双注入、人格漂移。

## 八、边界与已知问题

```text
语义召回      能力齐了但没接入运行时（实测：接上后负例拒识从 4/10 掉到 0/10）
跨会话记忆    scope 严格隔离，刻意不做（A 群的话不该出现在 B 的私聊）
模型抽取      纯规则，不调模型；句式一变就漏，这是已知代价
注入同义词    注入路径走字符重合判定，与 recall 是两套逻辑，本版未统一
衰减验证      半衰期与状态权重已实现，但装机不足两周，没有跨天真实数据
拒识残余      15 条负例仍漏 9 条（稀有词巧合），词法统计分不开，调阈值只会开始误拒
```

这些"没做"不是谦虚，是边界。看到没做的能力，就知道别指望它。

## 九、贡献聚合数据（可选，不自动）

默认**不联网、不遥测**。想帮忙改进，手动导出聚合指标：

```text
node scripts/public-data-export.mjs \
  --data-dir "<QQA>/data/plugin-data/cognition-core/core" \
  --out public-data.json \
  --consent public-data-v1
```

```text
只导出计数与枚举分类：不含正文、QQ 号、路径、时间戳
所有分布单元少于 k=5 的会被抑制
没有 --consent public-data-v1 会拒绝运行
导出前可以自己打开看
```

协议全文：`docs/数据收集协议.md`。提交：`2736629638@qq.com`。
